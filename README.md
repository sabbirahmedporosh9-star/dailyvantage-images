# dailyvantage-images

Images for **The Daily Vantage** social posts (Instagram and Facebook).

Files are stored by date as `YYYY/MM/DD/<slot>-final.jpg` (slot = HHMM) and served via
`https://raw.githubusercontent.com/sabbirahmedporosh9-star/dailyvantage-images/main/YYYY/MM/DD/<slot>-final.jpg`.

Each image uses a freely licensed photo. Photo credits and licenses are listed per image in
[CREDITS.md](CREDITS.md) and are also shown on each image and in the post captions.
